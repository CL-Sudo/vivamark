# Third-party notices

vivamark contains no third-party code yet.

When code is copied from another project, add an entry here with: the project
and URL, its licence, the source commit, the files in vivamark that contain it,
and the copyright notice exactly as the source gives it.

## Fonts

The review page's themes use these typefaces. Each ships inside the package
as a Latin-subset WOFF2 file in `src/ui/fonts/` (copied to `dist/ui/fonts/`),
served by the local daemon only; nothing is fetched from the internet. All
are under the SIL Open Font License, Version 1.1; the full licence text for
each sits beside its file as `<family>.OFL.txt`. The files were taken
unmodified from the Fontsource npm packages named below (version 5.3.0),
which repackage the upstream releases.
